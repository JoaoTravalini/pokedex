# **📌 Descrição do Projeto - Pokédex**  
Este projeto consiste em uma Pokédex para visualização dos Pokémons e suas habilidades, utilizando **Angular** e **TypeScript**. O objetivo é praticar o uso do framework e as respectivas linguagens utilizadas.  

### 🎥 **Vídeo para visualização do projeto:**  
[Assista no Google Drive](https://drive.google.com/file/d/1lySm2I3GCtSge6VoE5bmNyiwJykB6ULM/view?usp=sharing)  

## 🛠 **Tecnologias Utilizadas**  
- Angular  
- HTML  
- CSS  
- JavaScript  
- TypeScript  

## 🚀 **Como executar o projeto**  
1. Clone o repositório 
2. Execute npm install no terminal do projeto
3. Execute ng s no terminal
